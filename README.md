# Gestión de Flota · Maipú Zona 6

> Tablero operativo para revisar vehículos, responsables y estado documental de la flota del contrato.

## 🚚 Acceso directo

### [ABRIR EL DASHBOARD DE FLOTA](https://nburgosfigueroa-bit.github.io/FLOTA-ZONA-6/)

[Ver repositorio en GitHub](https://github.com/nburgosfigueroa-bit/FLOTA-ZONA-6)

## 1. ¿Qué hace este proyecto?

Ordena la información operacional de la flota y facilita el control de vehículos, responsables y vencimientos documentales. Las fechas que no están respaldadas se mantienen pendientes, sin inventar información.

## 2. Información disponible

- Identificación y estado de los vehículos.
- Responsables asignados.
- Fechas de vencimiento documentales.
- Alertas para revisión y renovación.
- Vista web sencilla para consulta operativa.

## 3. Automatizaciones

- **Publicación web:** GitHub Pages presenta el acceso público alojado en la carpeta `docs`.
- **Carga del tablero:** la página abre el tablero interactivo de flota desde su publicación central.
- **Actualización de datos:** debe realizarse desde la fuente maestra del proyecto; este repositorio no documenta actualmente un envío programado por correo.
